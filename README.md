# Sintaxis_CSharp

Solución de la evidencia **220501097-04-AA1-EV03 – Aplicación de la sintaxis básica de C#:
Tipos de datos, Variables, constantes, operadores e Interpolación de String.**

## Descripción

En esta solución se desarrollan pequeños programas en C# que integran:

- Declaración y uso de tipos de datos.
- Definición de variables y constantes.
- Uso de operadores aritméticos y de asignación.
- Construcción de salidas por consola usando interpolación de strings.

## Estructura de la solución

```
Sintaxis_CSharp.slnx          Archivo de solución
├── Ejercicio1                Tipos de datos y constantes
├── Ejercicio2                Operadores aritméticos y de asignación
├── Ejercicio3                Interpolación de strings
├── RetoTiposDeDatos         Reto: declaración de variables con distintos tipos
└── RetoOperadores           Reto: área y perímetro de un rectángulo
```

## Requisitos

- Sistema operativo Windows, Linux o macOS.
- Editor de código (Visual Studio Code recomendado).
- SDK de .NET instalado (probado con .NET 10.0).

## Cómo compilar y ejecutar

Compilar toda la solución:

```bash
dotnet build Sintaxis_CSharp.slnx
```

Ejecutar un proyecto desde consola:

```bash
dotnet run --project Ejercicio1/Ejercicio1.csproj
dotnet run --project Ejercicio2/Ejercicio2.csproj
dotnet run --project Ejercicio3/Ejercicio3.csproj
dotnet run --project RetoTiposDeDatos/RetoTiposDeDatos.csproj
dotnet run --project RetoOperadores/RetoOperadores.csproj
```

## Evidencias de aprendizaje

- Repositorio con la solución y los proyectos con código fuente funcional.
- Ejecución correcta de los programas en consola.
- Resolución completa de los retos planteados.
